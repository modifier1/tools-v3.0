# SimSwap AI — نسخه آزمایشی اندروید

این پروژه یک پوسته اندرویدی فارسی برای انتخاب عکس و ویدئو و انتخاب حالت آنلاین/آفلاین است.

## ساخت APK بدون Android Studio
پس از ثبت فایل‌ها در GitHub، از تب Actions گردش‌کار **Build SimSwap AI APK** را اجرا کنید. فایل APK آزمایشی در بخش Artifacts قرار می‌گیرد.

## وضعیت
- رابط فارسی و انتخاب فایل: پیاده‌سازی شده
- آیکن برنامه: اضافه شده
- ساخت APK ابری: تنظیم شده
- موتور واقعی SimSwap آنلاین: هنوز به سرور GPU متصل نشده
- موتور آفلاین: مدل ONNX هنوز ادغام نشده

این نسخه برای آزمایش رابط کاربری است و هنوز تعویض چهره انجام نمی‌دهد. برای استفاده فقط از تصاویر و ویدئوهایی استفاده کنید که اجازه استفاده از آن‌ها را دارید.
